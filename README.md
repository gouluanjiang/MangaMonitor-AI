# MangaMonitor

Windows 桌面漫画库、JM／哔咔浏览与下载工具。你手动检查关注作者的作品，从收藏、搜索或最近更新中选择下载；成功保存后登记到电脑漫画库，并可在程序内或独立小窗阅读。

当前正式版为 **[1.0.1](https://github.com/gouluanjiang/MangaMonitor-AI/releases/tag/v1.0.1)**，约定的 V1 开发、验收、合并、发布及本机升级已完成。V1 使用体验、阅读器、界面和项目审查修复已由用户验收；全部关注作者检查摘要及本补丁的 JM 分页边界修复已完成代理实机核验。最终 CI、安装、完整退出重开与数据保留检查均已通过；没有启用云端自动监控。

## 已有功能

| 功能 | 当前行为 |
| --- | --- |
| 电脑漫画库 | 读取本地目录、浏览 ZIP、筛选待核对文件，按入库时间或本地下载版本的更新时间排序 |
| 在线收藏、作者搜索 | 分别查询 JM／哔咔，显示已入库／未入库，按已读取范围筛选；读完分页后给出完成统计 |
| 关注作者更新 | 手动检查一个或全部关注作者，复用目录进行增量检查，保留未下载的旧遗漏 |
| 最近更新与榜单 | 浏览来源最近更新，以及 JM 周榜／哔咔榜单，支持连续翻页 |
| 下载队列 | 单本或批量准备、确认、暂停与重试；一本一个 ZIP，成功后登记；显示下载中、需要处理、已下载 |
| 漫画阅读 | 纵向滚动、单页翻页、缩放、进度条、阅读位置；多个独立小窗及可选置顶 |
| 账号与外观 | 可选记住会话；JM 可选记住登录；自定义背景、封面密度和动效 |
| 诊断 | 查看版本／提交号，复制不包含账号、作品标题和私人路径的状态摘要 |

入库判定依赖同来源下载记录、已核对的旧库登记与实际文件。**不通过相似标题猜测两条记录是否为同一本**，也不自动跨站合并。语言标记沿用网站提供的标签，缺少依据时显示未知。网站查询范围、读取失败和未完成范围会明确显示。

## 安装与数据

桌面版面向 Windows x64，依赖 Microsoft Edge WebView2。安装包为当前用户安装；缺少 WebView2 时可能联网下载运行时，因此不是完全离线安装包。当前未配置代码签名。安装名称保留 MangaMonitor Dev，以沿用已有安装登记。

为沿用现有数据，保留应用标识 `com.mangamonitor.workbench.preview`、私有目录 `workbench-preview-v1`、原凭据命名空间及内部 EXE 名称。展示名或版本变化不代表建立新的漫画库。安装程序与主程序均不附带账号、私人书目或漫画。

安装前关闭主窗口和所有阅读小窗。不要同时运行不同版本，也不要直接用旧 EXE 打开新版已经写入的数据。详细数据位置、重开方式及验证范围见使用指南与发行记录。

## 开发

前端位于 [apps/local-workbench](apps/local-workbench/README.md)，Tauri 原生工作区位于其 `src-tauri` 目录。使用 Node 24、pnpm 11.19.0、Rust 1.98.1；依赖由锁文件固定。

正式检查与构建在 GitHub Actions 执行：前端逻辑／Chromium、Rust 基线、Windows 原生／WebView 和安装验证。本地不重复执行同一套正式检查。贡献与问题反馈见 [CONTRIBUTING.md](CONTRIBUTING.md)，具体开发约束见 [AGENTS.md](AGENTS.md)。

浏览器预览是合成数据样例；真实账号、电脑漫画库及下载由 Windows 桌面端提供。测试通过、用户验收、公开发行是不同状态。
