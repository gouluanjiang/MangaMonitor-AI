- Source repository: `gouluanjiang/MangaMonitor`
- Source branch: `main`

## Deliberately excluded work

The No-AI project's unfinished local Matcher M4 work was not imported. Only material committed to the source repository at the frozen import point is part of this baseline.

## Isolation rule

`gouluanjiang/MangaMonitor` is the independent No-AI project and is read-only from the perspective of this repository.

Changes made here MUST NOT be pushed, merged, synchronized, or written back automatically to the No-AI repository.

Future improvements from the No-AI project may be brought into this repository only by an explicit, reviewed, one-way migration from No-AI -> AI.

## Safety intent

The AI project may diverge freely above this baseline, but it must preserve the useful deterministic infrastructure already built: source adapters, state model, catalog/fingerprint change detection, checkpoint/resume, review/decisions, pending task revisioning, inventory identity separation, and fail-closed safety behavior.
