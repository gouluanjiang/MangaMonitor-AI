# Third-party notices for MangaMonitor

MangaMonitor's own code is provided under the root `LICENSE`. The following
upstream notices cover the manually reused or referenced material recorded in
this repository. Original module-level notices remain in place.

The Windows candidate also includes `licenses/THIRD_PARTY_LICENSES.txt` and
`licenses/inventory.json`, generated by `scripts/collect-release-licenses.mjs`
from the frozen installed npm production graph and the locked Windows native
normal/build dependency graph. Those files contain each dependency's declared
license, supplied license/notice text, version, public source and text hashes.
Build dependencies are conservatively included; development/test-only dependency
edges are excluded. They are not an inventory of separately installed Windows,
WebView2 or development tools, nor a claim that every listed build dependency is
embedded in the executable. Missing declarations or license text fail collection.
Only CI generates these files; no registry trees or machine paths are distributed.

Some exact published crates omit license text. Their reviewed archive-bound
supplements, original text sources and selected license options are documented in
`third-party/dependency-licenses/README.md` and `manifest.json`. The collector
verifies exact versions, declarations, archive and text hashes; it never fills
an arbitrary missing license from an SPDX name. The generated resources preserve
each supplement's provenance and versioned source archive link.
