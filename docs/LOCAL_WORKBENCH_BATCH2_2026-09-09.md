# 第二批开发报告：桌面基础与本地书单

日期：2026-09-09。延续分支：codex/local-workbench-preview；现有草稿 PR #19。

## 批次范围与当前状态

本批在已经确认的主界面与设置基线上增加 Windows Tauri 2 开发壳、原生本地偏好和书单存储、原生背景选择，以及混合来源书单管理。作品、账号与队列仍是明确标识的模拟数据；原生偏好和书单写入是真实文件操作。没有启用生产、连接真实账号、执行漫画下载或更改漫画库存。

代码已集成，云端验证及主线程界面复核进行中。此段将在最终验收后替换为精确提交和结果，不能作为已完成验收的证明。

## 已实现功能

1. Windows 桌面开发壳：固定主窗口、受限导航与五项 IPC 命令；独立 GUI 锁文件及 Windows 构建流水线。
2. 原生存储：偏好和书单分开存储，严格版本/字段校验、版本冲突检测、跨进程锁和临时文件同步后原子替换。读取错误或未来版本保留原文；IPC 保存完成后界面才显示成功。存储不可用时保留窗口和重新读取入口。
3. 原生背景：用户通过系统选择器挑选 PNG/JPEG/WebP，校验真实内容、大小和尺寸，最多 8 MiB；保存后缓存图片字节，原文件移动不影响已保存背景。浏览器预览仍限制 2 MiB。选取取消和保存失败保留原草稿。
4. 混合来源本地书单：新建、重命名、一部作品加入多个书单、移出成员、归档及恢复。来源与作品 ID 共同标识成员；重名、重复成员、数量上限和未知引用有明确处理。归档和移出不会删除漫画文件。
5. 整理选择与下载资格分开：已入库、排队和待复核作品均可加入书单；下载动作继续检查原有资格。支持当前筛选全部选择、离屏成员、详情页加入及返回书单上下文。
6. 失败和并发处理：异步加载/保存、防止重复提交、冲突拒绝覆盖、保留表单草稿；浏览器使用独立书单键，原生故障不会回退成浏览器成功。
