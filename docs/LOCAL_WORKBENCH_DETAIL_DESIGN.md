# 独立作品详情页：静态设计讨论稿

日期：2026-09-09。状态：用户认可整体方向并接受三项微调，微调版静态预览已交付；未实施正式界面或接入账号、队列、文件。

依据：[已确认产品行为](LOCAL_WORKBENCH_V1_DESIGN.md)、[功能范围](LOCAL_WORKBENCH_FEATURE_SCOPE.md)、[页面与外观决定](LOCAL_WORKBENCH_UI_STRUCTURE.md)。用户说“开始下一步”，承接独立详情页布局讨论，不重新询问已确认的阅读器、ZIP、队列或背景选择。

## 本轮范围与验收

制作同一套 B 背景、窄图标导航的两张静态预览，供用户判断大封面、介绍、来源和操作的排列：

1. 在线收藏进入的未入库作品，以“下载并入库”为主操作。
2. 漫画库进入的已入库作品，以“打开文件位置”为主操作，提供 PDF/CBZ 导出入口。

验收检查：两张图采用相同窗口尺寸与主体布局；入口和库存状态一致；网站收藏、书单、作品关注和作者关注分开；章节只展示目录；图片清楚标为示例数据，没有阅读器、逐章下载或旧包补更入口。文件可解码、文档引用有效；不为静态稿运行项目构建或测试。

## 布局提案

- 沿用 B 顶部背景渐隐；正式应用仍支持既定 A/B 切换，不为详情页新增独立背景规则。
- 左上返回原列表，恢复该列表的搜索、筛选和浏览位置；全局窄导航与搜索沿用图库样式。详情页不显示只用于封面网格的 5/7/9 密度按钮。
- 左侧大封面，下方只显示库存状态与简短文件/打包信息，不堆叠统计卡片。
- 右侧依次为标题、作者与“关注作者”、标签及内容规模、来源、主要操作、简介。
- 下方页内标签为“章节目录 / 来源信息 / 本地文件”，不另加一级导航。
- 预览作品使用原创虚构作品“雾港来信”、示例作者“青岚”和演示账号，不声称它真实存在于 JM/哔咔或用户漫画库中。

### 用户已接受的微调

用户先表示两种状态“都还好”，随后明确要求“按你说的微调吧，然后我们进行下一步”。保留大封面比例与整体布局，按以下三项调整：

1. 下载/打开文件位置仍是醒目的主按钮；导出保留次级按钮，网站收藏、书单、关注改成更轻的图标文字入口。
2. 已入库后的“另存一份”移到“来源信息”标签内，主信息区只保留实际文件来源。微调版已入库图选中“来源信息”，便于检查移动后的入口；原本地文件标签仍保留。
3. 长简介默认展示约两行并提供“展开简介/收起”，短简介完整展示且不出现无意义的展开按钮。预览用末尾省略号表示长简介折叠状态；展开后页面正常向下延伸，不新增嵌套滚动区。

## 操作与状态

| 状态 | 主操作 | 其他行为 |
| --- | --- | --- |
| 未入库、未排队 | 下载并入库 | 展示本次来源、整部作品和保存位置后一次确认；确认后按已有规则自动进入队列 |
| 已排队或正在下载 | 查看队列 | 显示任务状态，重复点击不新增相同任务 |
| 已入库、文件存在 | 打开文件位置 | 提供 PDF/CBZ 额外导出；原 ZIP 保留；导出粒度仍按后续细则确定 |
| 已入库、等待同步 | 打开文件位置 | 提示等待同步，恢复只补同步，不重新下载 |
| 任务失败 | 查看任务 / 重试失败项 | 保留可恢复任务，显示实际失败阶段 |
| 本地文件失联 | 查看文件问题 | 不把缺失文件显示为可正常打开，不擅自开始重新下载 |
| 来源关系未确定 | 查看来源与复核 | 不把不确定关系展示成“同版”；独立来源对象及已确认下载遵守原有规则 |

本轮只画前述两种正常状态，其他状态为已有功能的布局约束，尚未完成交互设计或执行验收。

## 收藏、书单与关注

- 从 JM 在线收藏进入的示例显示“JM 已收藏”和“JM · 演示账号”，不会再次显示为未收藏。收藏按钮允许单作收藏/取消收藏，实际完成需读回确认。
- 网站收藏状态按来源和账号分别读取；切到哔咔不能沿用 JM 状态。尚未登录、读取中或失败不能假装“未收藏”。
- “加入书单”只改变本地书单关联；“关注作品”和作者旁的“关注作者”明确各自目标。取消网站收藏不隐式删除本地文件或改变这些关系。

## 来源、目录与文件

- 未入库时标注“本次下载来源”；只有已经可靠确认同作同版本才提供同版来源切换。预览中的“已确认同版”明确属于虚构示例状态，不来自真实匹配结果。
- 切换本次来源后，详情、章节和网站收藏状态按该来源更新；确认下载时明确实际来源。不能将某来源的页数或完整性信息直接沿用到另一来源。
- 已入库时显示实际“文件来源”，查看另一来源不改写既有文件。需要保留另一份时通过明确的另存流程与确认，避免把换源表现成覆盖旧 ZIP。
- 章节目录没有复选框、阅读按钮或单章下载按钮；下载粒度仍为整部作品、一个 ZIP、内部按章节分目录。
- 本地文件标签只展示实际文件信息和可用操作；示例路径使用演示漫画库，不读取用户真实目录。默认平铺 `漫画库/作品名.zip`，不新增作者文件夹。
- 导出提供 PDF/CBZ 入口，不将导出视为修改默认保存格式；导出进度沿用“下载”入口。
