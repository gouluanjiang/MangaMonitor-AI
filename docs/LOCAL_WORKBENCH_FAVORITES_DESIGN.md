# 在线收藏页：静态设计讨论稿

日期：2026-09-09。状态：JM/哔咔两种来源的静态预览已交付；用户回复“没有什么需要调整的地方了”，本页视觉设计按交付稿确认。未登录账号、读取真实收藏或执行下载。

依据：[功能范围](LOCAL_WORKBENCH_FEATURE_SCOPE.md)、[页面与外观决定](LOCAL_WORKBENCH_UI_STRUCTURE.md)、[详情页微调](LOCAL_WORKBENCH_DETAIL_DESIGN.md)。用户要求完成详情微调后进入下一步，当前仍是共同设计阶段。

## 本轮计划与验收

1. JM：展示来源、演示账号、已有网站收藏夹、库存筛选、勾选作品及批量下载。
2. 哔咔：使用同一套布局，展示独立账号和收藏列表；不显示未经确认的远端收藏夹功能。
3. 核对数值与范围自洽、选择数量正确、来源能力与库存状态明确；检查图片解码、尺寸和文档引用。不运行本地项目构建或测试。

默认采用已确认的 B 顶部渐隐与窄图标导航，封面网格继续提供 5/7/9 三档切换。截图只是示例数据，原始作品和账号都属虚构。

## 首屏排列

- 标题“在线收藏”，JM/哔咔来源切换，当前来源的示例账号、读取范围和最近刷新时间。
- JM 显示“网站收藏夹”选择器，只列网站已有的收藏夹；哔咔省略此行控件，保留“收藏作品”及当前来源的补齐操作。本地书单继续独立命名。
- 库存筛选作为一行小标签：全部、已入库、已排队、未下载、需复核，不制作大统计卡片。
- 新收藏用轻量提示与“查看待确认”入口表达，进入“发现 → 新发现”。它是当前收藏的子集，数量不与总数相加。
- 主区采用与图库一致的多行封面网格，按当前密度从左到右排满后换下一行，通过上下滚动浏览后续作品；不采用单行横向封面滑动。卡片标题、作者和库存状态清楚分开。点击进入已有独立详情页，单作取消网站收藏保留在详情/次级操作中。
- 多选时显示明确勾选框与底部操作栏；无勾选时操作栏隐藏，避免空的“下载所选”按钮占空间。上下滚动保留勾选；为固定底栏预留空间，最后一排作品能够完整显示。

## 批量操作的范围

| 操作 | 默认范围 | 点击后的行为 |
| --- | --- | --- |
| 下载所选 | 明确勾选的作品 | 展示所选范围的下载计划，一次确认后入队；JM 示例为 4 部未下载作品 |
| 补齐全部收藏 | 当前来源、当前账号的完整收藏 | 先完成对应范围读取与库存核对，再展示计划；JM 示例为可下载 8、已入库跳过 10、已排队跳过 4、需复核 2 |
| 补齐指定收藏夹 | JM 选定的网站收藏夹 | 操作名称写出收藏夹，预览范围限于它，不能隐式变成全部收藏 |
| 加入书单 | 明确勾选的作品 | 修改本地书单关联，与网站收藏及下载任务分开 |
| 查看待确认 | 当前来源的新发现条目 | 进入新发现汇总，按已确认方式批量确认；刷新本身不会自动批准下载 |

状态筛选主要服务浏览。补齐按钮应明确它针对完整收藏/选定收藏夹，不随状态筛选静默改变范围；如果用户只想处理筛选出的部分，可通过勾选及下载所选完成。确认页始终再次显示实际范围。已入库、已排队和需复核不能直接合并进可下载数量。

切换来源或账号时清空临时勾选，不把 JM 的选择/收藏状态带到哔咔。各来源的筛选与排序可分别记忆；刷新后只保留仍属于同一范围且仍存在的选择。只有已经确认的任务才有持久队列意义，临时勾选不表示下载授权。

## 读取与异常反馈

- 未登录：显示连接当前来源账号的入口，不显示虚假的空收藏。
- 首次读取/分页中：显示实际进度；当前已读页不代表完整收藏。
- 分页失败：保留已读内容，显示“部分收藏未读取”和重试入口。完整范围未读全时，补齐应先补全读取；失败则停在可理解的状态，不生成假完整计划。
- 账号失效与网络失败分开提示；收藏写入需要按来源账号读回确认，不能只凭爱心变色认定完成。
- 同一作品从多入口选中不能重复入队。已可靠入库的同版本默认跳过，另存其他来源从详情的来源信息进入。

## 保持既定范围

本页不增加批量取消远端收藏、远端文件夹新建/改名/移动/删除、阅读器、逐章下载、备份或批量文本链接导入。后续内容继续作为新作品发现，不引入旧 ZIP 补章。

本页已制作两个正常状态的静态示例；下一步进入[批量确认和下载队列](LOCAL_WORKBENCH_QUEUE_DESIGN.md)。未登录、部分读取和其他异常页面尚未绘制，真实账号、队列与文件功能也尚未接入。
