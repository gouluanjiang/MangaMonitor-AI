# 本地工作台：功能范围与待定行为

更新日期：2026-09-09。本文记录产品决定，不是功能交付或测试通过声明。

## 当前讨论边界

用户先确认功能，再共同确认 UI。此前浏览器样例未获视觉认可；后续 Seanime 方向、窄图标导航、独立详情/队列、5/7/9 封面密度、A/B 背景（首次 B）和各页面设计已完成讨论。2026-09-09 用户要求删除作者头像及 ZIP/图像处理调节项，其余无问题并推进下一步，正式前端恢复实施；本次和以后不再生成修改预览图。最新状态见 [LOCAL_WORKBENCH_UI_STRUCTURE.md](LOCAL_WORKBENCH_UI_STRUCTURE.md)。

本轮用户明确确认：“选项2按你的建议来吧 然后你说的值得加入或补齐的功能也全部添加”。“选项2按建议”指两源单作收藏/取消收藏与跨来源本地书单；上一轮最终回复的功能建议全部纳入，包括排行/每周必看及 PDF/CBZ 导出。随后用户修正“连载补章”的场景：后续内容按新漫画作品发现与下载，不需要旧 ZIP 追加章节、重打包或版本替换。以下清单以这次修正为准，按依赖分步实现和验收，尚无全部完成声明。

## 已确认需求

| 编号 | 功能 | 确认的范围 |
| --- | --- | --- |
| F01 | 两源账号与收藏读取 | JM、哔咔都纳入首版，先后实现验收；分别登录，读取收藏，JM 可按已有网站收藏夹浏览 |
| F02 | 网站收藏写入 | 应用内对单部作品收藏/取消收藏；JM 与哔咔各自实现并确认实际结果 |
| F03 | 本地书单 | 本地创建、改名、整理书单，可混合 JM/哔咔作品；书单关联不改变已确认的作品 ZIP 文件层级 |
| F04 | 收藏与库存对照 | 展示已入库、已排队、未下载、新发现与待处理状态；同作同版本默认只下载一个来源，可手动换源或另存一份；歧义继续复核 |
| F05 | 自动发现与批量补齐 | 新增收藏自动发现并汇总，批量确认一次后下载；下载所选、补齐当前收藏夹和全部收藏，范围明确 |
| F06 | 持久队列与失败恢复 | 暂停/继续、安全退出后恢复；失败清单跨重启保留，只重试失败部分；单作异常不阻断独立任务 |
| F07 | 搜索与直接添加 | 关键词搜索、来源编号/链接添加；不要求用户先关注作者或在网站收藏该作品 |
| F08 | 作品/作者关注 | 从收藏或作品入口加入关注与作者监控，发现后续新作品；关注作者与只收藏该作品分开表达 |
| F09 | 库与元数据 | 兼容已有 ZIP/CBZ，读取封面；保存原始标题、作者、标签、来源与章节信息，支持元数据随作品保留 |
| F10 | 资源与诊断 | 资源档位、同时下载作品与全局图片请求上限；图像处理和 ZIP 打包不暴露为独立控件，内部仍有界执行必要步骤；明确错误阶段、脱敏诊断 |
| F11 | 后续新作品发现 | 按用户使用场景，后续内容作为新的漫画作品处理，进入发现、库存对照与批量确认；不做旧 ZIP 补章、重打包或版本替换 |
| F12 | 发现内容 | JM 每周必看、哔咔排行榜；与来源搜索共同提供手动选书入口 |
| F13 | 可选导出 | PDF/CBZ 导出纳入功能范围；新增作品默认仍是一部一个 ZIP，导出粒度和外部兼容在设计/验收中明确 |

自动发现默认随桌面应用运行，在应用关闭时遵守安全暂停并退出的既有选择。首次扫描和后续新增都应汇总明确的批量计划；不把“自动发现”解释为今后所有作品无需确认即可下载。

个人账号、收藏和本地书单默认留在本机；账号材料使用安全存储、按账号隔离缓存，不进入普通日志或公共状态。既有云端监控的认证与必要库存/完成状态同步仍按独立契约设计。

## 明确后置或待证实的能力

- JM 网站收藏夹完整管理（创建、重命名、删除、移动作品）：按已接受建议另设后续阶段，需先核实接口与操作结果。
- 哔咔网站分组管理：目前没有充分实现依据；不能把本地书单宣称为已经同步到网站的文件夹。
- 首版不做阅读器。托盘常驻、开机自启及自动安装更新未获选择。

“以后实现某项功能”与“现在操作账号或文件”是不同阶段。本轮仅记录需求；现有生产、真实任务和文件执行策略不因此自动改变。

## 已收敛的行为与设计默认值

1. **新作品而非旧包补章**：旧 ZIP 更新方案从当前产品范围移除。此处是按用户场景确定的产品规则，不是关于 JM/Pica 所有作品和接口的普遍技术结论。若实际来源记录发生内容变化，先如实标记需要处理，不自动改写现有 ZIP，也不伪造新的来源 ID。
2. **相同版本的跨来源保存**：用户已选择默认只下载一个来源，可手动切换或另存另一份。译本、修订版、内容差异及不确定身份单列。下载前换源需要重新绑定所选目标；已入库后的另存不覆盖原文件，不自动混合两源内容。
3. **设计默认值，未新增额外功能**：收藏、关注、本地书单、已确认下载任务分别保留关系；取消收藏默认不删除本地文件、不清除书单、不自动取消已确认任务。单作可以加入多个本地书单，仅增加关联。用户后续仍可调整这些默认行为。
4. **导出细则**：PDF/CBZ 的粒度、图片格式和压缩策略在具体流程设计时说明；任意章节下载和批量取消远端收藏不因可选导出已确认而自动扩入首版。

不需要再次询问已确认的 ZIP 层级、退出方式、是否内置阅读器和队列确认方式。自动刷新间隔、失败重试上限、缓存和资源档位初值属于实施时可提出并验证的默认配置，不必为每个数值中断产品讨论。

## 后续实施与验收

- 当前功能与页面设计已收敛，按最新删减开始前端实施，不再继续添加未确认的功能或生成新预览图。
- 按依赖推进账户/收藏、书单与库存对照、选书与关注、持久队列及 ZIP 完整链；排行和可选导出仍在已确认清单内，不能漏交。

- 队列、ZIP、入库与云端同步要验证正常路径、异常隔离、关闭重启、丢失回执与仅补同步；已确认的产品行为见 [LOCAL_WORKBENCH_V1_DESIGN.md](LOCAL_WORKBENCH_V1_DESIGN.md)。
