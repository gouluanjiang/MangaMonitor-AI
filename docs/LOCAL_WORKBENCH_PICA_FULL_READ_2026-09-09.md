# 哔咔主动切换排序后读取完整收藏目录

日期：2026-09-09。目标版本：0.3.4。本文件记录实现范围，最终 CI、安装包与用户验收尚待补全。

## 用户选定的方案

普通进入哔咔收藏页仍按浏览位置分批读取。主动将“收藏时间：从新到旧”与“收藏时间：从旧到新”相互切换时，程序按选定方向自动连续读取全部收藏目录；完成后可搜索整个目录中的标题和作者，无需手动滚到底。已完整读取并缓存的方向先核对首页，再复用目录，不无条件重新扫一遍。

JM 保留已验收的原逻辑；哔咔仍使用来源原生时间顺序。读取沿用已有单任务、逐页请求和间隔，没有提高并发或新增隐式重试。封面仅对需要显示的卡片读取，仍在本次程序运行内复用；不提前加载全部封面或持久保存封面图片。

## 实现与边界

- 全读请求只由主动切换两个时间方向触发，按账号会话、收藏夹和目标方向绑定，由匹配的读取器消费一次。
- 换向时暂停旧读取器；同账号旧方向迟到的结果不能覆盖当前列表。
- 暂停、设置页往返、继续及失败后的手动重试保持相应进度和读取方向；限流不会触发连续自动重试。
- 本地输入筛选不取消已经主动开始的全读。标题排序、普通刷新、换来源/账号不自行启动新的全读；普通刷新恢复按需读取。
- 完整目录时搜索框明确提示“搜索全部收藏的作品或作者”；未完整时继续明确筛选范围。
- 首页核对不能证明网站其他位置没有变化；完整目录是已取得的快照，不承诺网站实时一致。分页变化仍要求核对或刷新。

## 验证计划与执行分工

主 Agent 实施与独立复核；只读子 Agent 审查状态交接及回归。合成浏览器用例覆盖两向读完、末页标题/作者搜索、缓存复用、暂停设置继续、旧方向迟到、限流后手动重试和取消全读。保留已有 1876 条分页、2000 条目录及虚拟列表回归。

本机仅作源码编辑/审查（格式化写入属于编辑，不运行格式检查或测试）及后续工件校验；正式测试、格式/类型检查、构建、安装包及原生 Windows 验证只在 CI 执行，不在两边重复。

用户报告 JM 约 500 本在 20～30 秒读取完，这是用户粗略计时，并非性能基准，也不用于承诺哔咔耗时。未对真实收藏做自动扫描、压测、收藏写入或漫画下载。
