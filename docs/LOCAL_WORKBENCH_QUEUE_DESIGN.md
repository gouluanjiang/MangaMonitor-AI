## 进度、恢复与完成的含义

- 页数百分比只表示下载图片阶段的进度，不能直接当作下载、校验、打包、入库、同步整个流程的总完成率。
- 图片下载结束后还需要校验、打包、验证压缩包与入库，再同步状态。本轮截图未穷举每个短暂状态；不能因此跳过对应实现检查。
- “已入库，等待同步”明确表示本地 ZIP 已保存。重试只补状态同步，不重复获取图片或覆盖现有文件。
- “需要处理”保留可恢复任务及可理解的原因。重试失败项复用已验证进度，单个作品失败不阻止互不依赖的正常任务；账号失效、磁盘不足等共同故障应暂停受影响范围并说明原因。
- “已完成”仅用于实际完成入库与状态同步的任务；不能仅凭下载进度 100% 显示完成。
- 暂停在可安全保存的边界生效。关闭窗口时显示保存进度/安全暂停过程，结束后退出，下次打开按可验证进度恢复。无需托盘驻留或开机自启。

这些是已确认产品流程的 UI 表达。静态稿不改变仓库的任务授权、真实执行、入库、库存发布和生产验收要求，也不能作为任一阶段已经接通的证据。
