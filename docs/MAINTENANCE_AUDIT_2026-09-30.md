## 实施范围

| 范围 | 最终行为与验证重点 |
| --- | --- |
| A1 下载容量与放弃 | 活跃任务与留存记录分别计数；放弃不会偷偷删除文件。独立清理只处理当前 root、command、manifest 证明的暂存对象，拒绝未知文件、未知目录与链接；最终 ZIP 不参与清理。 |
| A2 ZIP 重复检查 | 保留四个完整文件哈希边界；同一文件身份、哈希、manifest 下复用已验证条目布局；变化或冷启动重新检查。合成测试记录四次完整哈希与一次条目扫描。 |
| A3–A7 下载恢复与说明 | 有界读取轮询恢复、工作线程意外退出显式报告、登记失败给出可理解原因、暂停说明与真实行为一致、来源范围内分批继续任务。 |
| B1–B2 目录重扫 | 紧凑基线跨中断/重启保留未重新读到记录的身份、时间和关联；只有重新观察到相同文件才恢复登记。基线不算已入库，不用于打开文件；完整扫描后清除失效基线。不同目录选择先确认影响，并复查 revision/root。 |
| B4–B5 目录错误与筛选 | 区分损坏、不兼容、冲突和读写不可用；只优化重复过滤与排序计算，不恢复已取消的标题匹配。 |
| C1–C2 阅读进度 | 保存失败保留待保存位置；重试或明确放弃本次位置后关闭，原生关闭和页内返回一致；未知章节不发送非法位置。 |
| D1–D3、D6 诊断/说明 | 复制反馈稳定显示；诊断只纳入白名单错误码、来源与时间，不带私人路径、标题、账号；说明过滤、分页与当前操作入口。 |

B3（冷启动自动扫描）、D4（默认单来源）、D5（账号信息未清理）不按外部报告扩建；现有代码已具备对应保护，回归保留。
