## 验证边界

1.0.2 重新由 CI 构建；版本说明更新不替代准确源码的基础、前端和 Windows 原生／安装检查。CI、Windows 专项和用户体验是不同证据。

本地 37 项专项收尾为 **28 通过、0 失败、0 受阻、8 项用户决定不再测试、1 项留待用户自然体验**。各项保留自己的提交与测试层次，不称为 37 项在最终包上全部原生通过，也不重启已取消项目。

LOCAL-01 最近更新元数据回写、LOCAL-02 占用文件拒绝回收后的库存状态均已修复并定向复测。测试合成文件已经移出漫画库，测试登记已清理；正式发行不附带测试漫画或私人资料。

## 已知边界与后续

- **LOCAL-03**：CI 冷启动最近更新页曾有 15 像素滚动偏差，同源码重跑通过，根因未定；仍保留问题记录，没有宣称修复。
- 本机 NSIS 安装尝试遇到临时目录错误，最终通过已核验发行载荷原位更新；应用文件、原桌面入口和资料保留已确认。窗口工具未恢复，本轮更新后的原生画面检查未完成，详见发行记录。
- 特别关注的真实自然更新提醒由用户日后实际体验；模拟测试不替代该验收。取消的长时间 Windows 性能等测试不补写通过结论。
- 网站缺失元数据、限流、登录失效和未完成分页仍会影响可查询范围。JM 不包含网页端 English Manga 分类；“完整”指本次支持范围的完整读取，不保证网站提供全部出版物。
- Windows 包未代码签名；缺少 WebView2 时可能联网安装。旧程序不能安全打开格式版本 2 资料，升级前备份，不无条件降级。
- 后续以实际使用问题和用户新确认需求进入维护。字体／按钮进一步优化、内置更新器留待单独讨论，不在本次收尾擅自扩展。

应用标识、私有目录和凭据命名空间沿用既有值，安装名称保留 MangaMonitor Dev。云端自动监控保持关闭，`production_enabled=false` 不变。自动猜测匹配、跨站版本推断与替换、不喜欢标记、托盘／自启等此前取消的范围不因历史计划重新进入待办。

接手开发先读 [当前交接](DEVELOPMENT_HANDOFF.md)和 [文档导航](README.md)，核对当前 main 和工作区状态。历史工作树、候选包、个人核对清单不作为当前正式版本身份；私有安装与资料证据保留在仓库外。
