更新日期：2026-09-29。**当前正式版为 [1.0.1](https://github.com/gouluanjiang/MangaMonitor-AI/releases/tag/v1.0.1)，约定的 V1 开发与正式交付已完成。** 本页是当前范围总览；按日期保存的路线图、候选版报告和交接章节用于追溯历史，不应重新变成待办。

## 已交付功能

| 范围 | 已完成的行为 |
| --- | --- |
| 电脑漫画库 | 读取本地 ZIP、筛选与浏览；按入库时间或本地下载版本更新时间排序；保留经核对的旧库登记 |
| JM／哔咔浏览 | 登录与会话恢复、在线收藏、作者搜索、最近更新、榜单、连续分页、作品详情与下载入口 |
| 入库状态 | 根据同来源下载记录、已核对登记及实际文件显示状态；成功下载登记后更新页面；文件缺失不会继续无条件显示已入库 |
| 关注作者更新 | 手动检查单个或全部作者；增量复用目录、完整复核、未完成范围、检查变化摘要与本次新发现筛选；旧遗漏继续保留 |
| 作者检索准确性 | 查询词处理、作者归属区分及经核对的定向规则；其他关键词结果不进入默认作者统计或批量选择 |
| 下载队列 | 单本／批量准备和确认、暂停与重试；下载中、需要处理、已下载三类；一本一个 ZIP 并完成入库登记 |
| 阅读 | 程序内阅读及多个独立小窗；纵向滚动、单页翻页、缩放、进度条、阅读位置、全屏和可选置顶 |
| 显示与体验 | 时间显示、来源标签语言标记、封面加载优化、运行期封面缓存、自定义背景、整合界面及动效 |
| 账号与诊断 | JM 可选记住登录、两源会话恢复；版本与提交号及不包含私人书目和凭据的诊断摘要 |

## 已知边界

仍有一条来源作品记录缺少可用元数据，对应范围明确保留为未完成，其余正常结果可用。这是已核实的来源限制，不是未完成的开发任务；软件不能承诺恢复网站没有提供的信息，也不保证网站持续可用。

JM 搜索范围不含网页端 English Manga 分类。完整结果指本次支持范围内已读取的全部分页；作者归属与语言字段缺少依据时仍保留未知或未核对状态。软件不通过相似标题猜测同本，也不自动跨站合并。

当前 Windows 安装包未配置代码签名；缺少 WebView2 时可能联网安装运行时。已验证的安装、原生窗口和来源行为范围以发行记录为准，未遇到的所有网站异常不因此视作已经实测。

## 后续范围

已约定的 V1 功能没有待开发欠项。后续以实际使用问题和用户新确认的需求进入维护；**内置更新器留待以后讨论**，没有已批准的下一批实现计划。云端自动监控保持关闭，`production_enabled=false` 不变。

自动猜测匹配、跨站版本推断与自动替换、手机名单、分类书单、不喜欢标记、PDF／CBZ 导出，以及先前取消的复杂断网恢复、备份恢复、远端收藏夹完整管理、托盘／自启和独立 TXT 编号导入，不是待补的 V1 功能。内置阅读器与整体 UI 优化已经交付，不再列为冻结项。

源码续接使用 canonical `MangaMonitor-AI` checkout 和当前 `main`，以[文档导航](README.md)与[当前交接](DEVELOPMENT_HANDOFF.md)作为入口。历史工作树和旧安装产物不是续接目标；本机清理明细与必要的私有交付记录保留在仓库之外，不公开私人目录、书目或账户资料。仓库文档整理不会重建或替换已发布的 1.0.1 安装包。
