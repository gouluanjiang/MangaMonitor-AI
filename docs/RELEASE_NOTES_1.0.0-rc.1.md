# MangaMonitor 1.0.0-rc.1

这是供安装验收的 Windows x64 发行候选版，不是已经公开发布的正式 V1。此前桌面功能、阅读器、界面及四项审查修复已经用户验收。

## 本次发行整理

- 统一应用版本为 1.0.0-rc.1，设置中的诊断面板显示实际版本与构建提交。
- 更新已经过时的项目、前端与原生说明，提供当前使用指南；旧说明保留为历史记录。
- 将本项目 MIT 许可、手工参考／适配通知、锁定依赖许可清单与文本纳入候选交付。
- 在现有 Windows CI 中验证候选安装器生命周期，并生成可核对版本、提交与 SHA-256 的交付清单。

## 本候选包含的最近修复

1. 清理完成历史后，不再因同路径另一 ZIP 被重扫而误认旧作品已入库。
2. 临时搜索分页总量变化时保留已读结果并明确未完成，续读也沿用原基准。
3. 纵向阅读短尾页正确显示章末；极端缩小后的短图保持可见页渲染，保留阅读锚点。
4. 同名 ZIP 在准备、确认与执行前发现冲突，减少无效下载；原文件不会覆盖。

## 兼容与候选边界

- 安装产品名称暂保留 **MangaMonitor Dev**。应用标识、私有目录、凭据槽和内部 EXE 名称沿用既有值；不能为了去掉“Dev”而断开原安装或数据登记。
- 当前用户安装；未配置代码签名；缺少 WebView2 时可能需要下载运行时。
- CI 的同候选重装／卸载再安装，不等同于真实旧 0.3.4 安装器到新版本的升级验证。实际验证结果及未完成事项以发行记录为准。
- 新版保存的数据不保证能被旧二进制读取，不支持直接降级打开同一份新数据。
- 未新增内置更新器、模糊匹配、跨站合并或自动替换。未启用云端自动监控，也不附带私人书目或漫画。
- 网站返回内容和分页可能变化；来源故障不能被解释为作品不存在。稳定总数本身不保证查询具备快照一致性。

完整操作方法见随包 USER_GUIDE.md；候选工程状态见仓库 docs/RELEASE_CANDIDATE_2026-09-27.md。
