# MangaMonitor 1.0.0

Windows x64 桌面版。已验收的 1.0.0-rc.1 升为正式版本，保留其功能和数据格式；本次调整版本、窗口标题、发行资料与稳定版打包流程。

## 功能

- 电脑 ZIP 漫画库、入库状态与时间排序。
- JM／哔咔在线收藏、作者搜索、手动关注作者更新检查，保留历史未下载作品。
- 最近更新与榜单、来源语言标记、运行期间封面缓存。
- 单本／批量下载、进度与错误处理，保存完成后登记到漫画库。
- 程序内阅读、多个独立阅读小窗、缩放、阅读进度与可选置顶。
- 可选记住会话、JM 记住登录、自定义背景与界面动效。

## 更新与兼容

安装名称继续使用 **MangaMonitor Dev**，应用内显示 MangaMonitor 和实际 1.0.0 版本。保留应用标识、私有数据目录、Windows 凭据命名空间、内部程序名，沿用现有漫画库登记和设置。

安装前关闭主窗口及所有阅读小窗。安装范围为当前用户；安装包尚未配置代码签名。缺少 WebView2 时可能联网安装运行时。新版本写入的数据不保证能被旧程序读取，不支持直接降级打开同一份新数据。

## 验证与已知范围

候选版功能及安装已经用户验收。正式构建仍执行现有前端、Rust、Windows 原生与安装生命周期检查；具体提交、结果和文件哈希见发行清单与发行记录。

“本次检查变化”区分本轮首次发现的来源编号与历史已知作品，不表示网站刚刚发布。多轮单作者实测已完成；全部关注作者场景的实机验收安排在正式版收尾之后，验收记录单独公布。

来源查询可能失败或出现分页变化，未完成范围会明确保留；不保证网站持续可用。JM 搜索不包含网页端 English Manga 分类。入库状态依赖同来源下载记录、已核对登记与实际文件，不进行标题猜测或自动跨站合并。

本版不启用云端自动监控，不包含自动更新器、账号、私人书目或漫画。使用方法见随包 USER_GUIDE.md；发行记录见 docs/RELEASE_1.0.0_2026-09-29.md。
