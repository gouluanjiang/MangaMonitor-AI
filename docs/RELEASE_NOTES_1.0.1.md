# MangaMonitor 1.0.1

Windows x64 桌面补丁版，修复 JM 搜索与关注作者检查遇到相邻分页边界重复记录时的计数和完成状态。

## 修复

- 仅在来源总数稳定且已知、相邻页末尾与开头的同一条记录完整一致时，识别该边界重复。搜索结果与作者检查按唯一作品计数，避免把这种分页重叠误报为未完成。
- 原始读取量仍计入检查预算；跨页恢复及增量检查沿用同一规则，保留历史作品、首次发现标记和未完成范围。
- 缺失元数据或分页冲突仍明确保留；非相邻重复及总数未知的结果不获得此边界兼容例外，不通过忽略异常来宣称完整。

## 更新与兼容

安装名称继续使用 **MangaMonitor Dev**，应用内显示 MangaMonitor 和实际 1.0.1 版本。沿用原有应用标识、私有数据目录、Windows 凭据命名空间、内部程序名及设置，无需更名迁移。

安装前关闭主窗口及所有阅读小窗。安装范围为当前用户；安装包尚未配置代码签名。缺少 WebView2 时可能联网安装运行时。新版本写入的数据不保证能被旧程序读取，不支持直接降级打开同一份新数据。

## 验证与范围

分页修复已通过此前修复提交的 CI 和限定范围原生实机验收。1.0.1 最终构建证据以发行清单 `manifest.json` 为准；安装与发布结果见 [1.0.1 正式发行页](https://github.com/gouluanjiang/MangaMonitor-AI/releases/tag/v1.0.1)。

“本次检查变化”表示本轮首次发现的来源编号，不表示网站刚刚发布。来源查询与元数据仍可能失败；已完成的检查不保证网站持续可用。JM 搜索范围、入库核对和下载确认规则保持不变。

本版不启用云端自动监控，不包含自动更新器、账号、私人书目或漫画。使用方法见随包 `USER_GUIDE.md`。
