# 1.0.2-rc.1 候选版

此版本用于维护批次验收，不代表已正式发布或用户已验收。

- 最近更新的未知标签作品先按需核验，成功后展示；明确 BL、AI 标签及 JM 女性向标签隐藏。核验失败可以直接重试，未核验作品不进入批量下载。
- 同一目录重扫保留尚未重新读到的登记基线，中断或再次重扫不丢失旧入库时间与来源关联；更换不同目录前说明影响。
- 下载任务可放弃；暂存清理单独执行，只处理能确认属于该任务的文件。改善容量计算、轮询恢复、入库失败说明、大量任务继续处理与工作线程异常退出提示。
- 保留 ZIP 完整哈希验证，减少同一份已验证 ZIP 的重复目录扫描。
- 阅读进度保存失败时可重试；关闭前可明确选择放弃本次未保存位置。诊断摘要增加经过脱敏的错误类别与发生时间。
- 沿用本批浏览位置、直接下载、封面菜单与作者目录完整性修复。

资料兼容：漫画库、下载队列与作者目录支持读取旧格式；读取只在内存转换，正常保存后使用版本 2。旧程序会提示不支持新格式，不能混用两个版本或将候选程序降回旧程序读取已保存的新资料。漫画 ZIP、账号凭据与正式版发行资产不会随源码更新自动迁移或删除。

首次浏览未知标签作品会多一些等待。过滤依据网站明确标签，不猜测图片画风；网站漏标或后来更改标签无法作绝对保证。
