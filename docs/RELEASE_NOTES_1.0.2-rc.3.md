# 1.0.2-rc.3 候选版

此版本用于夜间维护验收，尚未正式发布。包含 rc.2 的已有标签过滤、封面等待解除和最近更新并行读取改动。

- 同一程序内对同一资料目录的读写统一排队，避免大目录操作使另一个本地读取误报繁忙。跨进程锁、版本检查、原子保存和冲突检查继续生效。
- 作者目录上下文等待本地资料时释放账号状态锁，封面请求和账号切换不再被这段等待阻塞；返回前重新核对会话身份。
- 最近更新的补录与历史读取失败保留简短诊断代码，便于区分存储、会话和格式问题；不暴露账号、私人路径或原始错误内容。

完整退出后应通过已核验目标的快捷方式启动兼容版本。旧程序无法读取版本 2 的资料，并不代表资料丢失。候选验收与正式发布分开记录。
