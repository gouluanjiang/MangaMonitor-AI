# MangaMonitor 1.0.2

本版汇总浏览与下载体验、作者工作区、漫画库操作、长回归修复和 Windows 定向修复。正式包重新由 CI 构建，不将旧候选包改名为正式版。

## 使用变化

- 作者搜索优先显示已保存结果，按批次更新；独立作者标签保留各自结果与位置，多标签自动换行。关闭标签后清理其临时位置，迟到响应不会重建标签。
- 特别关注独立保存基线和未读作品；首次基线未完成不会把全部旧作当新作。冷启动后的检查与手动作者扫描共用调度。
- 最近更新可组合 JM 与哔咔浏览。按来源和作品编号合并历史与新记录，保留详情补充的元数据及浏览位置；可靠归入作者更新的同来源作品不重复展示。
- 最近更新和作者更新的浏览新增角标按每次启动固定基准；扫描新增、特别关注未读分别维护。
- 单本与批量下载直接提交，不再二次确认或跳转下载页；失败任务可以重试，异常提示不打断浏览。
- 漫画库右键菜单新增打开文件位置及删除；删除须确认并移入 Windows 回收站，没有永久删除兜底。文件被阅读器占用而拒绝回收时，保留原有可用状态。
- 浏览历史保存最近 100 本，支持封面、清空和关闭记录；详情可以直接加入特别关注。
- 封面有限自动重试、重复请求合并；作者目录、元数据保存与大列表更新减少不必要等待和计算。修复不合法控制字符导致的下载元数据错误分类。

## 过滤与来源边界

保留明确标签的 BL／耽美、AI 作画和 JM 女性向过滤。未知标签直接显示，不为过滤逐本查询详情，不依据标题、作者或封面猜测。正常打开详情取得的新标签会更新列表，不中断已打开的阅读器。

JM 的支持搜索范围仍不含网页端 English Manga 分类；来源缺失、限流、登录失效和未读完范围仍明确提示。入库身份依赖可靠登记和实际文件，不恢复模糊匹配或自动跨站合并。云端自动监控保持关闭。

## 升级与兼容

退出主窗口和所有阅读小窗后安装。沿用安装名称 MangaMonitor Dev、应用标识、资料目录和系统凭据命名空间；名称中的 Dev 不决定包是否正式，实际版本为 1.0.2。安装包不包含账号、私人书目或漫画。

旧登记资料在读取时只做内存兼容；后续正常保存可使用格式版本 2。旧程序不能安全操作新版资料，不支持无条件降级。升级前保留资料备份，不要同时运行新旧版本。安装为当前 Windows 用户；包尚未代码签名，缺少 WebView2 时可能联网安装运行时。

## 验证范围与已知事项

最终 1.0.2 的源码、CI、清单、哈希和本机安装证据见 [发行记录](RELEASE_1.0.2_2026-10-03.md)。历史 Windows 专项为分层、分提交证据：28 项通过，8 项由用户决定不再测试，1 项特别关注自然更新提醒留待用户日常体验；不称为 37 项全部通过。

LOCAL-01 最近更新元数据回写和 LOCAL-02 回收拒绝后的库存状态已修复并定向复测。LOCAL-03 曾在 CI 冷启动滚动位置检查中观察到 15 像素偏差，同提交重跑通过；原因仍未定，未宣称修复。多小时 Windows 资源稳定性等取消项没有新增通过结论。
