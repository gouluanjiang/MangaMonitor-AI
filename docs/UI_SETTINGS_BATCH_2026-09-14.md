# 漫画库操作与设置收尾

本批从 `729c415` 接续。上一批作者更新过滤修复、原 50 位与新增 50 位来源抽查已完成；本批不重复抽查，不把关键词结果当作已核实作者书目。

## 本批实现

- 漫画库详情增加“打开文件位置”。原生端接收当前库和作品标识，从已有索引核对文件身份后，在 Windows 文件资源管理器中定位该文件或目录。网页不能传入任意路径；文件移除、替换或目录切换后明确提示重新核对，不执行漫画文件。
- “网络与诊断”显示当前账号会话、漫画库、下载队列和设置状态，并提供账号管理、漫画库设置、队列入口。会话状态不是新完成的网络连通性测试；重新读取账号沿用现有会话读取，不新增网站探测、作者扫描或后台检查。
- 可复制只含版本、状态和数量的诊断摘要。按允许字段构造，不序列化账号、会话、作品或路径；复制不可用时保留可手动复制的文字。
- 版本信息显示实际原生应用版本与构建编号。CI 构建将本次分支提交写入程序，便于区分同为 Dev 0.3.4 的交付文件。
- 设置记住本次使用的分类，各页面的账号入口直接打开账号分类；诊断页能直接进入漫画库设置。搜索支持“壁纸”“记住会话”“版本”等控件关键词，自动显示匹配分类；无结果时不保留无关表单，切换分类仍保留未保存外观草稿。
- 设置数据读取失败时，原生诊断和账号／漫画库入口仍可访问，外观编辑和保存保持不可用，避免用默认值覆盖未读取设置。
- 清理本地书单、待接入自动监控、人工关联等已取消功能的残留提示，保持实际运行语义。

当前下载并发、队列容量、ZIP、图片请求、入库判定和来源搜索范围均沿用既有实现；本批没有修改下载执行契约。程序内作者／漫画身份匹配仍取消，存量辅助核对留到 V1 后。

## 检查与边界

新增合成回归覆盖：只定位当前作品；错误库代次、未知标识、修改／删除后的文件不交给定位操作；新命令的主窗口和来源权限；原生版本返回字段；诊断摘要不带私人字段；复制失败可手动处理；设置快捷入口、关键词搜索、草稿保留和设置失败时的诊断可达性。

代码与回归已准备，正式测试、构建和截图检查待本批 CI。基准沿用 `detail-02-imported-v2.png` 与 `settings-accounts.png` 的详情左右构图、主按钮和设置二级分类；保留后来取消项的删减。CI 生成的合成页面需要与这些既有基准目视比较，不能仅凭测试文件存在声称视觉通过。

不扫描或整理实际漫画库，不操作真实账号登录／关注，不下载或删除漫画。本批没有生成安装包或自动启动 Dev。Windows 系统文件管理器的实际定位结果和真实桌面综合流程仍由用户验收；合成回归与工程检查不代替这一项。

## 路线位置

阶段 1–3 与榜单 → 完整范围批量选书 → 作者更新修复与 50＋50 抽查 → **当前：漫画库操作、设置与诊断收尾** → V1 综合候选版与连续流程验收。

综合验收继续覆盖：手动检查作者更新、选书下载、ZIP 成功入库、任意作者完整搜索、已入库／未入库筛选，以及收藏写入、实际文件位置和剩余界面一致性。对 Pica 关键词精度、未登记旧库和跨站同本保留既有范围说明。阅读器、应用内更新在 V1 后讨论；不恢复其他取消功能。
