# MangaMonitor 使用指南

适用范围：正式版 1.0.1 与维护候选 1.0.2-rc.1。下文直接下载、放弃任务、按需核验等新行为以候选版为准，不代表正式版已自动升级。安装名称保留 **MangaMonitor Dev**，用于沿用原安装登记与快捷方式；程序内可在“设置 → 网络与诊断”查看实际版本和提交号。

## 安装与第一次打开

1. 关闭 MangaMonitor 主窗口以及全部阅读小窗，再运行安装器。安装范围为当前 Windows 用户。
2. 若缺少 Microsoft Edge WebView2，安装器可能联网下载运行时。安装包未配置代码签名；使用发行页中能核对 SHA-256 的包。
3. 打开“设置 → 漫画库”，选择你的电脑漫画目录并等待读取完成。已有目录无需搬迁到安装目录。
4. 在“设置 → 账号与收藏”分别登录 JM 和哔咔。账号、密码只填在应用里，不要发到问题报告中。

安装并不附带漫画，也不会把漫画库、关注名单和账号上传到 GitHub。应用查询来源时需要网络；网站自身不可用或账号过期仍可能影响访问。

## 账号与登录恢复

- “记住会话”保存来源会话，供下次启动恢复。
- JM 另有可选“记住登录”：在 Windows 凭据管理器保存登录材料，先恢复会话，明确过期后才尝试一次自动登录；普通网络错误不会反复登录。
- 哔咔保持会话恢复方式。忘记／退出相应账号时会清除该账号保存的凭据。
- 勾选与否由你决定。凭据不写入普通设置文件，也不进入诊断摘要。

## 看更新、找作者、下载

常用流程是：**作者更新 → 手动检查 → 筛选未入库 → 点击下载 → 成功保存并登记 → 漫画库阅读**。单本和批量下载不再二次确认，也不自动跳到下载页；遇到异常会给出短暂提示。

你也可以从在线收藏、作者搜索、最近更新和榜单进入作品。JM 与哔咔分别计数；作者搜索会把作者字段不能对应的其他关键词结果另行保留，不混入默认作者结果与批量选择。

检查一个或全部关注作者由你主动开始。已有目录可复用进行增量检查；“完整复核”读取所选范围全部分页，用于核对旧作补录等变化。未下载的旧作品不会因为再检查一次就自动消失。

查看页上的读取进度、总数与未完成范围：未读完不能当作全部结果。网站在搜索过程中改变分页数量时，应用会保留已读内容并提示未完成，可重新搜索。JM 当前搜索范围不含网页端 English Manga 分类；“全部”指本次受支持来源范围，而非作者所有出版物的保证。

## 已入库的含义

只以电脑漫画库为准。应用根据同来源成功下载记录、已核对的旧库登记和实际文件判断入库状态，不通过相似标题自动猜测，也不自动把两个网站的同本合并。

因此，有文件但没有可靠来源登记的旧漫画，或第一次遇到的另一站同本，可能仍显示未入库／待核对。不要把该状态当作文件一定不存在。已有旧库核对记录仍会保留。

在文件管理器移动、替换或删除漫画后，可重新读取目录核对状态。清除完成历史只清理历史展示和保留必要登记证据，不删除漫画。旧精简历史缺少原文件身份时会显示待核对，避免把同路径另一份文件误认为原作品。

## 下载队列

- “下载中”显示正在处理、等待或暂停的任务；“下载失败／需要处理”集中显示需重试或核对的问题；成功任务在“已下载”中查看。
- 单本与多选批量点击下载后直接提交。页面边缘有固定、不透明的多选入口；不同作品生成同名 ZIP 时提示冲突，不覆盖已有文件，也不会自行改名。
- 一本作品保存为一个 ZIP，保留相应元数据和章节结构。只有保存、验证及登记完成后才按成功入库处理。
- 失败时先看具体提示。重试复用可确认的已保存进度；目标文件改变、来源数据变化等需要核对，反复重试不一定能解决。
- “已下载”中的文件异常记录仍需处理。移除历史记录与删除电脑漫画是两件不同的事。
- 不再需要的失败或暂停任务可先放弃，暂存文件保留。若要释放暂存空间，单独选择清理；应用只清理能证明属于该任务的暂存对象，未知文件会阻止清理，漫画库最终 ZIP 不受影响。
- 队列读取暂时失败会有界退避重读。入库登记失败、文件异常与来源失败有不同提示；暂停期间正在完成的保存步骤会在安全位置停下。

## 阅读与小窗

右键封面打开“漫画详细”“程序内阅读”“手机小框阅读”菜单；普通点击聚焦封面，双击可进入小窗阅读，标题可打开详情。失败封面可直接重试。封面下的作者名字可进入双来源作者搜索，详情中的词条可进入该作品来源的词条搜索。

- 支持纵向滚动和单页翻页；Ctrl＋鼠标滚轮缩放。单页模式点击左半边向前、右半边向后，也可用键盘左右键。
- 鼠标移到底部显示工具栏。拖动进度条跳页；显示当前页／总页数，可选择章节。
- F11 或工具栏按钮切换全屏。返回后保留漫画库位置和阅读进度。
- 多本漫画可分别打开小窗；主程序仍可使用。置顶默认关闭，可按需打开。
- 关闭主窗口时若仍有阅读小窗，进程可能继续存在；要完全退出或更新，请关闭所有窗口。
- 暂时读取失败时可以重试，已经保存的阅读位置会保留。
- 阅读位置保存失败时，关闭/返回会保留重试机会；也可明确选择放弃本次尚未保存的位置。不能把失败提示当作进度已保存。

## 时间、封面与语言标记

来源列表使用网站更新时间；漫画库显示本地下载版本的更新时间与入库时间。没有可靠日期时显示未知，不从文件名猜测。

封面在本次运行中缓存并优先加载可见项，关闭应用后不作为永久封面库保留。语言标记依据来源标签：“已汉化”“生肉”“未知”；“生肉”表示未翻译版本，不保证一定是日文。

内容偏好仅使用已经取得的标签：明确 BL/耽美类、AI 作画类，以及 JM“女性向”标签的作品隐藏。未知标签正常显示，不为屏蔽额外读取详情，也不影响封面、阅读或下载选择。正常浏览详情等操作取得新标签后，列表自动更新，已经打开的阅读器继续阅读。网站没有标注的内容不能靠标签规则识别，AI 翻译标题不会直接算作 AI 作画。

最近更新会去除已可靠归入作者更新的同来源作品，已保存历史不因隐藏而删除。漫画浏览位置在本次运行的各页面分别保留；重开软件后重新开始浏览。筛选和计数只覆盖已读取范围，不代表整个网站。

## 数据位置与更新

电脑漫画保存在你选择的漫画目录。应用私有文档位于：

`%APPDATA%\com.mangamonitor.workbench.preview\workbench-preview-v1`

该标识、目录和原凭据命名空间保留是为了兼容旧版，不应手动改名或删除。安装不执行旧库重新核对，也不修改网站收藏或关注名单。

本次尚无内置更新器。安装更新前完全退出应用；避免同时运行两个版本。新凭据和下载历史字段不保证能被旧 EXE 读取，不能把留存旧程序理解为数据格式可无条件降级。安装器的具体已验证范围见本次发行记录。

1.0.2-rc.1 读取旧登记资料只在内存转换；漫画库、下载队列、作者目录后续正常保存采用格式版本 2。旧程序会明确提示不支持，不要再让旧程序操作该资料目录。选择另一个漫画库目录前会说明影响，取消选择不改当前登记；同一目录重扫保留待重新核对的旧信息，但尚未观察到的文件不冒充已入库。

卸载时如要保留设置和登记资料，不要勾选“删除应用数据”。本批验证的是不删除应用数据的卸载流程；漫画文件仍在你选择的漫画目录中。

## 遇到问题

打开“设置 → 网络与诊断”，查看版本与提交号，复制状态摘要，并说明操作步骤、预期与实际结果。候选版还会记录白名单错误类别、来源与发生时间；摘要不包含账号、私人路径、漫画标题、来源作品编号或登录凭据。不要另行粘贴整个私有数据文件。

“暂不可用／未完成”不等于作品已删除。网络恢复或重新登录后按当前提示重试；不会在你完全关闭程序后持续检查网站。
