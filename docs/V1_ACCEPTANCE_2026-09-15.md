# V1 候选版连续验收

这次用同一个 Dev 版本走完一条实际使用流程。选择自己确实想下载的少量作品即可，不需要遍历所有作者、重做旧库整理或重复百位作者抽查。

## 连续使用

1. 打开程序，进入“作者更新”。应显示上次保存的结果；只有点击“检查作者更新”才开始查询。等本次范围读完，核对进度、两站数量和未入库筛选。若某来源失败，应明确列出未完成范围，不能显示全部完成。
2. 选择一两本需要的作品，查看下载计划中的来源、标题与目标 ZIP，再确认下载。期间可在作者页和下载队列之间切换，返回时原有查询及筛选应保留。
3. 下载完成后返回作者页：刚下载的**同来源、同编号**作品自动转为已入库，从未入库筛选中消失；未选的作品继续留在列表中。无需手工刷新目录或重新登记。若该作品也在收藏或排行出现，那里的状态应一致。
4. 在“作者搜索”输入另一个作者名。等两站分页读完，查看总数、已入库数、未入库数，再筛选未入库并挑一本下载。切到队列后返回，搜索词、筛选及已读结果仍在；下载完成后统计自动更新。
5. 对一个本次完整查询结果均已登记的范围，应显示“本次查询结果已全部入库”，并标明来源、关键词和检查时间。没有适合的小范围样本可以跳过这一项，不需要为了验收而下载整位作者的作品。
6. 正常关闭后重开。关注作者检查结果与成功下载记录保留；程序不自动检查作者，不擅自重新开始暂停下载。临时的任意作者搜索重新输入即可。

## 前一批仍需确认的入口

- 漫画库作品详情的“打开文件位置”能在资源管理器中选中对应 ZIP。
- 设置中搜索“记住会话”等关键词，能进入对应分类；页面快捷入口指向正确设置。
- “网络与诊断”可复制当前状态摘要，显示实际版本与构建编号。

这些入口已经通过工程检查；若你已经实际使用并确认正常，无需重复操作。没有必要制造断网、删除文件或切换真实账号来测试边界，相关回归由合成场景覆盖。

## 统计口径

- 只按该来源的成功下载记录与实际文件判断入库。没有对应下载登记的旧库文件仍可能显示“未入库”；旧库辅助核对已移到 V1 之后。
- JM 和 Pica 不自动合并同一本的状态。两站关键词结果可能包含合著或其他命中，读完分页不代表核实了完整作者书目。
- JM 仍不包含 English Manga 分类。分页未完成或文件状态未知时，不应把临时统计误报成最终完整结果。

验收后说明哪一步正常、哪一步不符即可；如有问题，附来源、操作和提示文字，不需要提供账号密码。
