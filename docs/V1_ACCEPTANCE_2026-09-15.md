# V1 候选版连续使用与最终确认

更新于 2026-09-17。作者归属修复、旧缓存与新查询、全选排除、独立搜索、下载登记筛选、队列往返已有代理实机证据；此前下载／入库同步和重启证据按实际范围保留。网站收藏写入也已有用户选定样本的验收。设置关键词现已实测通过；当前先修复来源搜索／关注名单作者入口的遗漏，再补新修正版的实际确认，进度统一见 [收尾报告](V1_READINESS_2026-09-17.md)。

以下是完整日常流程，供最终体验确认，不是要求重做全部测试。无需重复百位作者抽查、全量收藏读取或旧库整理；只下载自己确实需要的作品。

用户当前要求暂停 Computer Use，因此以下原生交互暂不由代理继续操作。新的来源搜索作者模式、关注名单“搜索该作者”入口，以及误下文件删除后的库索引／未入库显示是后续需确认的具体项目。

## 连续使用

1. 打开程序，进入“作者更新”。应显示上次保存的结果；只有点击“检查作者更新”才开始查询。等本次范围读完，核对进度、两站数量和未入库筛选。作者字段能对应的作品进入默认列表；其他关键词结果单独保留，不混入作者统计或批量下载。若某来源失败，应明确列出未完成范围，不能显示全部完成。
2. 选择一两本需要的作品，查看下载计划中的来源、标题与目标 ZIP，再确认下载。期间可在作者页和下载队列之间切换，返回时原有查询及筛选应保留。
3. 下载完成后返回作者页：刚下载的**同来源、同编号**作品自动转为已入库，从未入库筛选中消失；未选的作品继续留在列表中。无需手工刷新目录或重新登记。若该作品也在收藏或排行出现，那里的状态应一致。
4. 在“作者搜索”输入另一个作者名。等两站分页读完，查看总数、已入库数、未入库数，再筛选未入库并挑一本下载。切到队列后返回，搜索词、筛选及已读结果仍在；下载完成后统计自动更新。
5. 对一个分页完整、没有待确认作者结果且作者作品均已登记的范围，应显示“本次作者作品已全部入库”，并标明来源、关键词和检查时间。没有适合的小范围样本可以跳过这一项，不需要为了验收而下载整位作者的作品。
6. 正常关闭后重开。关注作者检查结果与成功下载记录保留；程序不自动检查作者，不擅自重新开始暂停下载。临时的任意作者搜索重新输入即可。

## 常用入口（已有结果不重复验收）

- 已实测：漫画库作品详情的“打开文件位置”在资源管理器中选中对应 ZIP。
- 已实测：设置搜索“记住会话”只显示账号与收藏分类，清空后恢复全部五项分类；页面快捷入口已有实测。
- 已实测：“网络与诊断”可复制当前状态摘要，显示实际版本与构建编号。

这些入口已经通过工程检查；若你已经实际使用并确认正常，无需重复操作。没有必要制造断网、删除文件或切换真实账号来测试边界，相关回归由合成场景覆盖。

## 统计口径

- 只按该来源的成功下载记录与实际文件判断入库。没有对应下载登记的旧库文件仍可能显示“未入库”；旧库辅助核对已移到 V1 之后。
- JM 和 Pica 不自动合并同一本的状态。支持明确列出的合著者和社团括号内作者；不能对应作者字段的命中保留在其他关键词结果中。读完分页不代表核实了完整作者书目。
- JM 仍不包含 English Manga 分类。分页未完成或文件状态未知时，不应把临时统计误报成最终完整结果。

验收后说明哪一步正常、哪一步不符即可；如有问题，附来源、操作和提示文字，不需要提供账号密码。
