## 本批修复

1. **切到下载队列后，作者搜索结果不再丢失。** 原来作者页在离开时卸载，搜索适配器及输入、筛选、选书状态随之销毁。现在两种作者页首次进入才创建，在本次运行中保留各自状态；返回时读取已有结果，不重新发起作者查询。关闭程序后，临时搜索仍按原约定重开；已保存的关注作者检查结果继续保留。
2. **正在执行的手动搜索可跨页面继续。** 页面隐藏时不轮询显示快照、不渲染封面与网格；用户已经点击开始的分页继续完成，返回即可看到进度或结果。账号会话变更会使旧搜索失效，旧请求返回后不再追加下一页，也不把旧账号结果显示给新账号。打开程序、进入页面或重启均不自动启动新的作者检查。
3. **目录读取失败时，各入口统一显示待核实。** 作者页与排行原来只检查下载凭据读取结果，漏传了漫画目录读取失败状态；现在与收藏及详情使用一致的边界，目录失败时不把旧快照作为有效入库统计，成功重读后恢复。

不改下载传输、ZIP 保存、入库凭据、文件存在性校验或确认权限。复用 [下载执行审查](DOWNLOAD_EXECUTOR_THAW_GATE.md) 与已有来源固定版本审查；本次没有新的媒体执行路径，不需要重做上游实现移植。

## 工程验证

新增四条跨页面 Chromium 场景，使用一个共享的合成服务状态，分别维护队列、不同 ZIP 条目和同来源下载凭据。模拟完成由服务模型更新数据，再让实际前端控制器与页面订阅状态；不是直接改页面文字。场景包括：

- 手动检查双来源 → 选两本并一次确认 → 自动入库 → 收藏和排行同步 → 搜索未关注作者全部分页 → 继续下载 → 完整查询全部入库提示 → 重启后保留记录、没有自动检查。
- 后续分页失败，保留已读结果和未完成范围；切换页面不隐式重试，由再次点击搜索启动新读取。
- 搜索途中去下载队列并返回；会话改变后，旧请求不能继续分页或污染新结果。
- 目录读取失败与重读恢复，作者页和排行采用统一的待核实口径。
