## 验收中发现并修复

诊断摘要的“文件待核对”数量与漫画库筛选不一致：摘要仅统计读取状态和错误，漏计页数为零或未知的文件。现复用漫画库的 `fileNeedsReview` 判定，保持已有文件和入库逻辑不变。回归样本同时覆盖健康文件、不可读文件、已索引但含错误文件、零页与未知页数文件。

代码修正待本次 CI 验证及修正版本的实际诊断复验。详细作品信息、文件路径和原始 UI 证据只保留在 Git 外的本地验收目录。
