## 实现范围

- 在线入库状态改为同来源编号的已完成下载凭据和实际文件。新增只读状态接口，独立于图片进度轮询；切换页面、窗口返回、库变化和新下载完成时刷新。
- 清空队列历史保留的精简完成凭据继续参与状态核对；路径整理迁移证据继续有效。旧漫画元数据、标题和人工关系不作为下载成功依据。
- 收藏、来源搜索、详情、作者结果共用状态与筛选。移除自动身份推断、人工关联、跨站配对、语言版本补齐和自动下载入口及对应运行代码。旧私人文档原样保留但不参与判定。
- 单来源搜索自动读完分页；双来源作者搜索不要求先关注。读取中是临时数量，停止、短页、重复页、错误和上限不宣称范围完成。大结果使用已有虚拟封面网格。
- 作者更新只在点击按钮后检查。读取上次结果不会检查；检查中可停止。旧未下载结果保留，选择下载沿用已验收的准备与确认流程。
- JM 每周必看支持期数／类型，哔咔支持周榜／日榜／月榜。复用当前来源账号、运行内封面、入库筛选、详情与明确下载操作。榜单 API 没有分页时，不伪造“下一页”；JM 返回数量不完整时显示未确认。
- 作者搜索与榜单详情返回保留原查询和选择；文本筛选不能让部分已入库作品冒充整个作者已经补齐。
- 当前每批最多 50 本的下载能力保留。更大完整范围的选书和内部批次调度仍是阶段 4 后续项目，不能将本轮交付写成 V1 全部完成。

## 下载契约复核

已复读 `DOWNLOAD_EXECUTOR_THAW_GATE.md` 及当前桌面下载实现。本次收缩身份判断与自动下载权限，没有更换 JM/Pica/Python 参考版本、来源协议、图片并发或完成定义，复用此前 ZIP/JM/Pica 下载审查证据。

下载完成仍要求来源与作品编号、会话、任务修订、库根身份、输出清单和已验证文件一致。已有目标不覆盖，下载失败不计入库，不自动删除旧包。移除人工关系带来的重复拦截时，仍保留同来源下载凭据、物理目标和明确缺失文件检查。新增只读接口不能触发下载、登记或写库。

## 集中验收建议

候选版交付后，由用户选择真实样本操作，不需要再次整理或关联旧漫画。

1. 作者更新：进入页面时只展示上次记录；点击检查后读两站，途中显示范围和进度。停止或来源失败不报全部完成；下次检查仍保留未选作品。
2. 任意作者：不关注也能搜索；完整读取后核对同来源已入库／未入库数量，切换筛选并进入详情返回，结果保留。
3. 手选一本未登记作品下载，ZIP 完整保存后同一来源收藏、详情、作者页面和榜单状态同步，无需重新扫库。另一站同本保持独立状态。
4. 从电脑移走一份本软件登记的测试作品，返回应用刷新后不再计为已入库；明确重新准备下载仍可用。普通旧文件无下载登记时不自动识别。
5. 发现页检查 JM 期数／类型和 Pica 周／日／月榜，核对来源排序、封面、筛选、详情返回和手选下载。
