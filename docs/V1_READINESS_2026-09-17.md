## 路线图

```text
范围确认 → 下载登记与统一状态 → 常用页面和完整分页
  → 手动作者更新／任意作者搜索 → 两站排行／完整范围选书／设置诊断
  → V1 综合验收：补齐所有作者入口 ← 当前
  → 当前修复 CI 与独立 Dev 工件
  → 获准后补原生交互和已删样本索引确认 → 最终产品确认／发布决定
  → V1 后再讨论旧库辅助核对、阅读器、应用内更新
```

正式套件和构建仅在 CI 跑；本机只承担不重复的编辑、诊断和工件校验。当前不做 Computer Use，也不通过另一套窗口操作绕开用户暂停要求。不另造功能批次、重复百位抽查或生成小版本安装包。

入库仍只依据对应来源成功下载记录加实际文件。旧库和跨站同一本不自动关联；JM 不含 English Manga。作者字段缺失／别名未确认的命中单独保留，不误称全部无关，也不算作已证实作者作品。身份匹配／关联、不喜欢、语言版本推断、自动替换、手机名单、分类书单等取消项不恢复。Dev 保持 0.3.4、PR #19 草稿未合并、生产关闭。
